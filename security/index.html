Report a security problem.

If you find a security problem in CodeShift Keyboard, CodeShift Terminal or this website, email apps@mygig.life.

What to include

  • Which app or page it affects, and the app version (Settings, then About) if you know it.
  • Your Android version and device.
  • The steps that show the problem, and what you expected to happen.

Please

  • Give us reasonable time to fix the problem before you publish details.
  • Do not access other people's data or test against servers that are not yours.

This page and security.txt are the only places we publish security contact details.

Not a security problem?

For questions or feedback about the apps, use the same address. For how the apps handle your data, see which privacy policy applies.
